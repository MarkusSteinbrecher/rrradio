rrradio is an internet radio app for iPhone.

It plays live radio streams from around the world. It is free, has no ads, requires no account, and does not collect personal data. This page describes what it does, how it works, and why it exists in the form it does.

Download on the App Store
01

What it is

rrradio is a native iOS application that plays internet radio. You open it, you pick a station, you listen. There is a search field, a list of stations, and a now-playing screen. There is a favorites list. There is no signup, no onboarding flow, no tutorial, and no personalised feed.

The same app exists as a web version at rrradio.org, which works in any modern browser including Android. The iOS app shares the same catalog and the same look, but adds lock-screen controls, CarPlay support, an Apple Watch companion, iCloud sync, and the kind of background-audio behaviour you'd expect from a first-party Apple app.

02

What it does

Catalog
~800 curated stations hand-verified by the maintainer, plus ~50,000 community streams from Radio Browser. Filterable by genre, country, or search.
Playback
Streams via AVPlayer. Supports MP3, AAC and HLS. Background-audio and lock-screen controls via Media Session. Works with AirPods, Bluetooth headphones, CarPlay.
Metadata
Shows the current artist and track when the broadcaster provides it. Twenty-plus broadcaster integrations (BBC, ORF, BR, SRG, RAI, RTBF, ARD…) plus generic ICY metadata over Icecast/Shoutcast.
Schedules
For broadcasters with a public schedule API (BBC, BR, ORF, HR), shows the current on-air programme and the day's grid.
Lyrics
Fetched from LRCLIB and Lyrics.ovh when a song match exists. Coverage is incomplete; the lyrics tab hides itself when there's nothing to show.
Library
Favorites (heart any station, drag to reorder). Recently played (auto, last twelve). Custom stations (paste an HTTPS stream URL).
Sleep timer
15, 30, 60, or 90 minutes. Stops playback when it fires.
iCloud sync
Favorites, custom stations, theme and listening preferences sync across your devices via your private iCloud database (CloudKit private). Apple sees encrypted blobs; nobody else sees them at all.
Apple Watch
A watchOS companion controls the iPhone's playback over Watch Connectivity: now-playing, play/pause/stop, skip favorite, launch a favorite station. The Watch app is remote-first; independent playback on the Watch is planned but not yet shipping.
Themes
Three color schemes, each in light or dark. Follows the system setting by default.

How it works, technically

The app launches and fetches the station catalog from rrradio.org/stations.json — a small JSON file (a few hundred kilobytes) built from open YAML data and published with each web release. The catalog is cached on disk for offline boot. Catalog updates land without an App Store release; new stations appear the moment they're added.

When you tap a station, an AVPlayer instance opens the stream URL directly. For HLS streams, ICY-style timed metadata flows through AVPlayerItem.timedMetadata. For broadcasters with a separate metadata endpoint (ORF audioapi, BBC Sounds, BR radioplayer.json, …), a per-station fetcher polls the endpoint at a sensible interval and surfaces the result.

Some broadcaster APIs lack CORS headers. In those cases the app routes through a small Cloudflare Worker proxy with a fixed allowlist of upstream hosts. The proxy adds nothing, stores nothing, and is the same proxy the web app uses.

The full source is on GitHub: rrradio-ios (the SwiftUI app) and rrradio (the web app, shared catalog, and proxy worker).

05

What it costs

Nothing. There is no paid tier, no in-app purchase, no subscription, no upgrade prompt, no advertising, no affiliate link, and no plan to introduce any of those later.

rrradio is a personal project. The infrastructure cost is on the order of a few dollars per month — GitHub Pages for the web app, Cloudflare Workers for the proxy, an Apple Developer membership at $99/year for App Store distribution. If usage ever grows past what one person can fund, the options on the table are donations or shutting it down, not advertising.

If you want to support it, the most useful things are: ⭐ the GitHub repos, tell someone who would like it, or file a bug when you find one.

06

What it collects about you

Nothing personally identifying. The iOS app does not contain a third-party analytics SDK. There is no account, so there is nothing to associate behaviour with. The App Store privacy nutrition label reads "Data Not Collected" across the board.

What does leave the device, and where:

  • Audio streams — fetched directly from the broadcaster (or via the allow-listed proxy when required). They see standard request metadata: IP address, user agent, the stream URL.
  • Station catalog — one fetch of stations.json from rrradio.org per launch, cached on disk.
  • Metadata APIs — when you play a station with a broadcaster metadata endpoint, that broadcaster sees polling requests.
  • iCloud sync — favorites and preferences sync via your own Apple ID's private database. Apple sees encrypted blobs. The rrradio maintainer does not.
  • Lyrics & cover art — looked up at LRCLIB / Lyrics.ovh / iTunes Search when a song is identified.

That's the full list. The full text of the privacy approach is in the web app's privacy page.

iPhone

The web app is fully open source. The iOS app source is on GitHub and you can build it yourself with Xcode 15 and a free Apple Developer account. Both are MIT-licensed.

09

FAQ

Why is it called rrradio?
Because the domain was available. Three r's are easier to type one-handed on a phone than two, and "radio" alone was taken everywhere.
Why "free, forever" — what's the catch?
There isn't one. It's a side project, not a business. The maintainer pays infrastructure costs out of pocket. If that ever stops being sustainable, the alternatives on the table are donations or shutting the project down — advertising and data collection are not.
Who maintains it?
One person, in their spare time, with help from contributors via pull requests. Issues and contributions are welcome on GitHub.
A station I want isn't in the catalog. What do I do?
Two options. Add it directly from the app (tap +, paste an HTTPS stream URL) — it'll be saved locally and synced to your other devices via iCloud. Or open a pull request on the catalog YAML in the public repo to add it for everyone.
A station plays but the artist/track info is wrong or missing.
Metadata depends on the broadcaster. Some publish a clean JSON feed; some embed it in the stream itself (ICY); some don't publish it at all. The Now Playing screen will show whatever's available, or nothing if there is nothing. File an issue if it's a curated station and we'll look at it.
Is there an Android version?
No native one. The web app at rrradio.org is a full progressive web app — Add to Home Screen on Android and it behaves like a native app, including lock-screen controls.
Does it work in the car / on AirPods / with Bluetooth?
Yes to all. Audio output and remote-control input go through the standard iOS Media Session, so anything that talks to that — CarPlay, AirPods squeeze, Bluetooth headset buttons, lock-screen widgets — works.
